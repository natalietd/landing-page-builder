# Сборщик лендингов — скилл (v2, RU)

Собирает конвертящие лендинги в **любой нише** по одной формуле:

> **наша структура × лучшие практики конкурентов, сделано на уровне эталона**

- **Наша структура** — 5 задач с весами (первый экран 5% · боли 15%, только если они есть у конкурентов · преимущества 20% · продукт 40% ·
  оффер и CTA 20%), два типа CTA, базовые правила. Одинакова везде.
- **Конкуренты** — 3–5 реальных лендингов снимаются и разбираются по блокам. То, что делает весь
  рынок, становится базовым уровнем; то, что хорошо делают лидеры, — берём; то, чего не делает
  никто, — наше позиционирование; визуальная система — как принято в нише.
- **Эталон** — четыре лендинга, выбранные владельцем как хорошие (muestralo, aicarouselmaker,
  ups-fit, saytext). Они задают планку: паттерны блоков, ремесло текста и визуала.

## Два режима

- **A. Собрать с нуля** — процесс ниже.
- **B. Улучшить дизайн** существующего лендинга — снять его, провести аудит по структуре и эталону,
  по каждой секции решить «оставить / перерисовать / сменить паттерн», чекпоинт с владельцем,
  правка на месте, QA до/после (`references/redesign.md`).

## Процесс (режим A)

1. **Бриф**: карточка проекта или несколько вопросов.
2. **Исследование конкурентов**: найти конкурентов и снять их страницы (`scripts/capture.mjs`).
3. **Разбор**: картина рынка по блокам → базовый уровень, лучшие практики, пробелы, визуальная
   система (`research/teardown.md`).
4. **План страницы**: наши 5 блоков, заполненные выбранными практиками. **Здесь владелец утверждает план.**
5. **Сборка**: страница.
6. **QA**: в браузере, против плана и против конкурентов.

## Файлы

```
landing-page-builder-ru/
├── SKILL.md                         # процесс + как сочетаются структура и конкуренты
├── references/
│   ├── reference-standard.md        # 4 эталонных лендинга: планка, паттерны, ремесло
│   ├── redesign.md                  # режим B: улучшить дизайн существующего лендинга
│   ├── brief.md                     # бриф по карточке, строка карточки → блок
│   ├── competitor-research.md       # поиск, съёмка, разбор, синтез (ядро)
│   ├── framework.md                 # 5 задач, правила по блокам, таблица плана
│   ├── visual-system.md             # визуальная система по конкурентам
│   ├── build.md                     # стек, тексты, медиа, CTA, оффер, QA, передача
│   └── examples.md                  # разобранные примеры из разных ниш
├── templates/teardown.md            # файл разбора для заполнения
└── scripts/
    ├── capture.mjs                  # скриншоты + извлечение структуры и визуала
    └── package.json
```

## Настройка скрипта съёмки (один раз)

```bash
npm install --prefix .cursor/skills/landing-page-builder-ru/scripts
```

Использует Chromium от Playwright, если он скачан, иначе установленный Google Chrome. Если нет ни
того, ни другого — ещё `npx playwright install chromium`.

```bash
node .cursor/skills/landing-page-builder-ru/scripts/capture.mjs --out research/competitors https://a.ru https://b.ru
```

Для каждой ссылки: `full.png`, `mobile.png`, `sections/NN.png` и `page.json` (структура, CTA, цены,
доказательства, шрифты, цвета). Баннеры cookie скрываются, согласие не даётся. Извлечение CTA и цветов —
эвристика, сверяйтесь со скриншотами.

## Установка

- **Claude Code:** скопируйте папку в `.claude/skills/` (проект) или `~/.claude/skills/` (глобально).
- **Cursor:** держите в `.cursor/skills/` или добавьте правило «Следуй
  `.cursor/skills/landing-page-builder-ru/SKILL.md`».
- **claude.ai:** загрузите zip папки (без `scripts/node_modules`) как скилл.

# Бриф

Собирай только то, что нужно плану. Сначала прочитай переписку — не переспрашивай то, что уже дали.

## Как получить бриф — два способа

- **(A) Ссылка на карточку проекта** (предпочтительно). Прочитай колонку **«Твой проект»**. Не
  открывается — попроси вставить эту колонку текстом или выгрузить CSV.
- **(B) Вопросы** — если карточки нет, задай блок ниже одним сообщением.

### Строка карточки → куда идёт

| Строка карточки | Куда |
|-----------------|------|
| Выгода от решения (главная + вторичные) | Заголовок (выгода) + Преимущества |
| Аватар / ситуация | Строка про аватар, рамка болей |
| Боль + Ситуация | Боли — только если блок есть у конкурентов; только реальные факты |
| Решение (пошаговый CJM) | Продукт → шаги «как работает» |
| Конкурентное преимущество | Преимущества; сверить с пробелами из разбора |
| Цена | Оффер (реальные цены + снятие риска) |
| Ограничения | Кого не обслуживаем — не обращаться к ним в текстах |
| Тип продукта (1 / 2 / 3) | Тип CTA: 3 = в продукт, 1/2 = звонок |
| Рынок и конкуренты / Конкурент + ссылка | Список конкурентов для исследования |

## Вопросы (только то, чего нет в карточке/переписке)

**Продукт:** что это одним предложением · живой или до запуска · для кого · главный результат ·
как работает в 3–4 шага.
**Оффер:** тип CTA (в продукт / звонок) и ссылка · что даёт «начать» (бесплатный тариф, триал,
мгновенный доступ) · цены · снятие риска · реальные доказательства (логотипы, цифры, отзывы, кейсы).
**Ассеты — проси файлы:** скриншоты/видео продукта, ссылка на демо, логотип/цвета/шрифты бренда, если есть.
**Конкуренты:** 2–5 ссылок, если знает (иначе скилл найдёт сам).
**Язык и тон:** язык страницы (не угадывай) · «вы» или «ты» · слова, которых избегать.

Если ответ из небольшого набора — дай 2–4 варианта на выбор. Один раунд вопросов, дальше — работа.

## Бриф на выходе (10 строк)

```
Продукт:       …
Аватар:        …
Главная выгода: …
Как работает:  1) … 2) … 3) …
Тип CTA:       в продукт → PRODUCT_URL=… | звонок → BOOKING_URL=…
Цена/оффер:    …
Доказательства: … (или нет)
Ассеты:        … (нет → TODO)
Язык:          … · тон …
Конкуренты:    … (или «найти»)
```

Никогда не выдумывай цену, доказательства или оффер. Нет — `TODO`, идём дальше.

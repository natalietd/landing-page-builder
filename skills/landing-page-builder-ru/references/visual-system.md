# Визуальная система — по конкурентам

Внешний вид берётся из ниши, а не из вкуса. Фиксируй её во время разбора, до любого CSS.

## 1. Чью систему повторять

1. Есть **брендбук** (или цвета, которые владелец прямо назвал брендом) → они побеждают; подгони их под паттерны ниши ниже.
   Стиль текущей страницы — **не** брендбук. В редизайне это то, что мы заменяем.
2. Владелец назвал сайт-референс → этот референс и есть система.
3. Иначе → **лидер категории** (или паттерн, общий для большинства набора). Покупатель уже доверяет
   этому виду; совпадение говорит «серьёзный игрок». Отличаемся содержанием и одним акцентом, а не
   спорящей эстетикой.
4. Опционально: владелец дал тему с tweakcn.com → она задаёт цвета/шрифты/скругления (shadcn/ui + Tailwind).

## 2. Что извлечь (из `page.json` + скриншотов)

| Пункт | Что записать |
|-------|--------------|
| Роли цветов | фон страницы · поверхность/карточка · текст · приглушённый текст · **один** акцент · граница |
| Шрифты | заголовочный + основной, начертания, размер/трекинг заголовков |
| Плотность | отступы секций, скругления, сколько на экране, максимальная ширина |
| Медиа | формат (скриншоты интерфейса, телефоны, вертикальное видео, фото, иллюстрации, 3D), обрамление, движение |
| CTA | форма (пилюля / скруглённая / квадратная), заливка, главная vs вторичная, количество |
| Настроение | светлое / тёмное, плоское / атмосферное, игривое / корпоративное / премиальное |

Запиши фиксацию в разбор: hex + шрифты + форма CTA + правило медиа.

## 3. Превратить в токены

```css
:root {
  --bg: …;         /* фон страницы */
  --surface: …;    /* карточки, на шаг от --bg */
  --fg: …;         /* основной текст */
  --fg-strong: …;  /* заголовки */
  --muted: …;
  --border: …;
  --accent: …;     /* одно семейство */
  --radius: …;
  --font-display: …;
  --font-body: …;
}
```

Везде используй токены — никаких разовых цветов. Шрифты: как у лидера, если они свободные (Google
Fonts / открытая лицензия); иначе ближайший свободный аналог.

## 4. Правила качества (любая ниша, светлая или тёмная)

Ниша задаёт палитру, настроение и формат медиа; уровень ремесла — `reference-standard.md` §4
(пара шрифтов, один акцент, ритм секций с одной контрастной полосой, реальный UI в рамке,
надзаголовки). Применяй оба.

- **Глубина, а не пустота.** Поверхности на шаг от фона, тонкие границы, мягкий градиент/свечение,
  если в нише принята атмосфера. Не делай плоскую страницу из чистого `#000`/`#fff`, если так не
  делает лидер.
- **Один акцент, маленький бюджет** (3–5 мест): ключевое слово или подчёркивание в H1, hover/focus
  CTA, выделенный тариф, номера шагов или тонкая рамка вокруг продукта. Без радуги, без акцента на
  каждом заголовке.
- **Основной текст** читаемый (15–17px), чуть мягче чистого чёрного/белого; нормальная шкала размеров.
- **Максимум два стиля CTA**: главный + вторичный (контурный). Форма — как у референса. Всегда
  hover + `:focus-visible`.
- **Подача медиа — как в нише**: обрамляй продукт так же, как лидер (рамка браузера, рамка
  устройства, вертикальное видео, чистое фото). Только реальные медиа продукта.
- Сначала мобильный: первый экран, визуал «как работает» и CTA должны работать на 375px.

## 5. Нельзя

- Придумывать эстетику, которая спорит с нишей (журнальный сериф на девтуле, неон у юристов,
  корпоративный синий у инструмента для креаторов), если владелец не просил.
- Копировать логотипы, иллюстрации, фото, скриншоты, иконки или фирменные цвета конкурентов 1:1 как
  *их* айдентику — повторяем систему, сохраняем свою идентичность.
- Добавлять секции, вкладки или украшения «чтобы смотрелось лучше». Структура — забота плана.

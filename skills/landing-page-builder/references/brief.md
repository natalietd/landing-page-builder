# Brief

Collect only what the plan needs. Read the thread first — never re-ask what's already given.

## Get the brief — two ways

- **(A) Project card URL** (preferred). Read the **«Твой проект»** column. Can't open it → ask the
  owner to paste that column or export CSV.
- **(B) Questions** — if no card, ask the block below in one batch.

### Card row → where it lands

| Card row | Lands in |
|----------|----------|
| Выгода от решения (main + secondary) | Headline (benefit style) + Benefits |
| Аватар / ситуация | Avatar line, pains framing |
| Боль + Ситуация | Pains — only if competitors use the block; real facts only |
| Решение (step-by-step CJM) | Product → how-it-works steps |
| Конкурентное преимущество | Benefits; check it against the teardown gaps |
| Цена | Offer (real prices + risk reversal) |
| Ограничения | Who we don't serve — don't address them in copy |
| Тип продукта (1 / 2 / 3) | CTA type: 3 = into the product, 1/2 = book a call |
| Рынок и конкуренты / Конкурент + ссылка | Competitor list for research |

## Questions (only what the card/thread doesn't answer)

**Product:** what it is in one sentence · live or pre-launch · who it's for · the main result ·
how it works in 3–4 steps.
**Offer:** CTA type (into product / book a call) and its URL · what "start" gives (free plan,
trial, instant access) · prices · risk reversal · real proof (logos, numbers, reviews, cases).
**Assets — ask for files:** product screenshots/video/demo link, brand logo/colors/fonts if any.
**Competitors:** 2–5 URLs if they know them (otherwise the skill finds them).
**Language & tone:** page language (don't assume) · formal/informal («вы»/«ты») · words to avoid.

Offer 2–4 clickable options when the answer is a small set. One round of questions, then move.

## Brief output (10 lines)

```
Product:      …
Avatar:       …
Main benefit: …
How it works: 1) … 2) … 3) …
CTA type:     into product → PRODUCT_URL=… | book a call → BOOKING_URL=…
Price/offer:  …
Proof:        … (or none)
Assets:       … (missing → TODO)
Language:     … · tone …
Competitors:  … (or "to find")
```

Never invent price, proof or offer. Missing → `TODO`, keep going.
